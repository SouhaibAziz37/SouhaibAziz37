## 👨‍💻 About Me

I'm a **Computer Science (AI) student** who enjoys turning ideas into working software — from small automation tools to computer vision experiments. I'm currently focused on strengthening my foundations in **software development, machine learning, and computer vision**, and picking up **web development** and **generative AI** along the way.

Most of what's on this profile comes from hands-on learning projects — I'd rather build something small and real than just study theory. Some of my recent work includes controlling system volume with hand gestures using OpenCV/MediaPipe, a desktop cafe management system in C#, and a couple of classic ML models (house price prediction, spam classification).

- 🎓 CS (AI) student
- 🧠 Interested in AI, Computer Vision & Machine Learning
- 🌱 Currently sharpening my Python, C#, and web dev fundamentals
- 💬 Open to learning opportunities, collaborations, and feedback
